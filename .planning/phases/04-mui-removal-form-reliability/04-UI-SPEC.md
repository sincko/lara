# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Contract type: PRESERVATION.** This phase removes MUI v4 from the contact form (`src/components/formik.js`) and top contacts (`src/components/top-contacts.js`) without a visual redesign (D-04). The contract locks the target plain-SCSS appearance derived from the existing theme variables (D-02) and documents every intentional delta from the MUI baseline in the Visual Delta Register below. The executor implements the TARGET column of that register.

## Visual Delta Register

> Intentional differences between the current MUI v4 rendering and the plain-SCSS target. Each delta is driven by a locked decision (D-02: theme variables, no new colors) or the site's established design language. The executor implements the TARGET column.

| Element | MUI v4 current | Plain-SCSS target | Driver |
|---------|----------------|-------------------|--------|
| Submit button background | #3f51b2 (MUI default indigo — no ThemeProvider exists in the codebase) | `var(--button-alternate-color)` #ff0060 | D-02 — theme variables only, no new colors |
| Submit button radius + shadow | 4px + MUI elevation shadow | 12px, no shadow | Site button language (`.button-pink`, style.scss:350) |
| Submit button hover | #303f9f (darker indigo) | background `var(--button-color)` #fff, text `var(--button-alternate-color)` | `.button-pink` hover pattern (style.scss:357-360) |
| Input border | underline only (MUI standard variant) | full box border 1px solid rgba(0,0,0,0.1); focus border-color `var(--input-focus-border)` | `--input-focus-border` exists in the theme for this purpose |
| Field label | floating label inside input, floats up on focus | placeholder-only (identical text) + aria-label | D-04 — placeholders preserved; label text equals placeholder text |
| Error color | #f44336 (MUI red) | `var(--primary-color)` #ff1c65 | No new colors; site's `.red` class uses `--primary-color` (style.scss:484-486) |
| Helper text color | rgba(0,0,0,0.54) | `var(--label-text)` rgba(0,0,0,0.5) | Theme variable |
| Button disabled while submitting | not present | added — `disabled={isSubmitting}` + opacity 0.7 | Phase goal: form reliability (double-send guard) |
| Icons (top-contacts) | MUI FacebookIcon/WhatsAppIcon, 24px | react-icons RiFacebookBoxLine/RiWhatsappLine, 24px | D-03 — same size, same color inheritance from `.icons-top a` (style.scss:54-64) |
