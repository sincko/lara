Swap node-sass ^9.0.0 for dart-sass (`sass` ^1.30.0, the peer dep of gatsby-plugin-sass 6.16.0) with no gatsby-config.js change (auto-detection, D-04), remove the now-dead Phase 2 node-sass hygiene guards (scripts/clean-node-sass-vendor.js + postinstall entry, D-05), and — in the same commit — hoist the two Google Fonts `@import url(...)` lines from the `:root` block of _theme-variables.scss to the top of style.scss (D-06 MANDATORY: dart-sass passes nested imports through in place, producing invalid CSS where browsers silently drop the fonts; the build stays green either way, so this is a silent-regression trap).
